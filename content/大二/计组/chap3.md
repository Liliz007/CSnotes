## （二）ALU

### slt：set on less than

进行有符号数比较

我们知道，有符号数比较的本质其实就是：rs<rt ⇔ rs−rt<0

因此，硬件中**不需要额外的比较器电路**，而是让 ALU **执行减法运算**：

D=rs−rt

然后检查 D 是否为负（sign bit = 1）。

---

#### ➤ 步骤：

|步骤|操作|含义|
|-|-|-|
|1️⃣|执行减法 `rs - rt`|ALU 内部完成|
|2️⃣|检查结果符号位 (sign bit)|若符号位=1 → rs<rt|
|3️⃣|输出|最低位 `rd[0]=1`，其余位为0|

即： rd=(rs<rt)?1:0



#### ➤ 溢出问题

当我们用补码做减法比较时，如果发生溢出，**单看 sign bit 可能出错**。

例如：

```C
rs = 0111 (+7)
rt = 1000 (-8)
rs - rt = 0111 - 1000 = 0111 + 1000 = 1111 (-1)
```


按符号位判断：结果为负数 → `rs<rt`
但其实 +7 > -8，判断错了。

---

#### ➤ 解决办法：考虑溢出位

ALU 在比较时会**综合 sign bit 与 overflow 标志位 (V)**：

slt=sign bit ⊕ overflow

|情况|实际结果|sign bit|overflow|sign ⊕ overflow|是否 rs<rt|
|-|-|-|-|-|-|
|正确比较|无溢出|s|0|s|✅ 正常判断|
|溢出导致符号错误|有溢出|s|1|反转符号位|✅ 修正|

从而在 ALU 的**比较功能（SLT）**部分：

1️⃣ 先进行普通减法（A - B）
2️⃣ 计算溢出标志 V=Cn​⊕Cn−1​
3️⃣ 计算 sign = 符号位（最高位）
4️⃣ 输出：less=sign⊕overflow

5️⃣ 结果只放在 **最低有效位（LSB）**，其余位清 0。



### Zero Detector

#### ➤ 用途：为了支持**条件分支指令**

在 RISC-V / MIPS 这样的 RISC 结构中，分支判断常常依赖“是否相等”：

```C
beq rs, rt, label     # branch if equal
bne rs, rt, label     # branch if not equal
```


但 ALU 本身只会做**算术运算**，它怎么知道两个寄存器是否相等呢？🤔

> ✅ 答案：通过 Zero detector！



### 注意

- RISC-V不包含nor指令

- 1 nibble = 4 bits = 0.5 byte.

## （五）浮点数

IEEE 754 定义了浮点数在硬件中的统一二进制表示方式。

### 通用形式

(−1)sign×(1.fraction)×2exponent−Bias

由三部分组成：

|字段|含义|位数（单精度）|位数（双精度）|
|-|-|-|-|
|**Sign**|符号位|1|1|
|**Exponent**|阶码（偏移表示）|8|11|
|**Fraction / Mantissa**|尾数（有效位）|23|52|
|**总计**||32 位（float）|64 位（double）|

### 浮点加法的过程（FP ADD）

浮点加法是浮点运算中最复杂的一个操作。

1️⃣ **对阶（Align exponents）**
 – 找出较小的指数，右移它的尾数直到指数相等。

2️⃣ **尾数相加/相减（Add/Sub mantissas）**
 – 根据符号执行加或减。

3️⃣ **规格化（Normalize result）**
 – 调整结果，使尾数恢复到 [1,2) 范围内，并修正指数。

4️⃣ **舍入（Round）**
 – IEEE 754 提供 4 种舍入模式（默认“round to nearest even”）。

5️⃣ **溢出/下溢处理（Overflow/Underflow）**
 – 若指数超出范围，置为 ±∞ 或 ±0。



### 浮点乘法与除法（FP MUL / DIV）

#### 🔹 乘法

(−1)S×(M1​×M2​)×2(E1​+E2​−Bias)

步骤：

1. 符号 = S1 XOR S2

2. 指数 = E1 + E2 - Bias

3. 尾数 = M1 × M2（结果2.x时规格化）

4. 舍入并检查溢出/下溢

####  🔹除法

过程类似，只是指数做减法。



### 舍留规则：保护位与扩展精度

- **Guard bit（G）**：对阶时被移出的第一位低位（最靠近保留尾数部分的第一位）。

- **Round bit（R）**：紧接在 G 之后的下一位。

- **Sticky bit（S）**：在对阶时被移出（丢弃）的所有剩余低位按位或（OR）得到的单一位，表示“是否有任何1被丢弃”。

通常在尾数右移并丢弃若干位时，会保留这 3 位（G,R,S）以便**正确舍入**。

|模式|条件|是否进位（+1）|说明|
|-|-|-|-|
|**RNE（最近偶数）**|G = 0|❌ 不进位|舍弃部分 < 0.5|
||G = 1 且 (R ∨ S = 1)|✅ 进位|舍弃部分 > 0.5|
||G = 1 且 (R ∨ S = 0) 且 LSB = 1|✅ 进位|恰好 0.5，取偶数（LSB = 1 → 变偶）|
||G = 1 且 (R ∨ S = 0) 且 LSB = 0|❌ 不进位|恰好 0.5，已是偶数|
|**RTZ（向 0）**|任意 G/R/S|❌ 不进位|永远截断|
|**RUP（向 +∞）**|舍弃部分 ≠ 0 且结果为正|✅ 进位|若正数且丢弃部分非零 → 加 1|
||舍弃部分 ≠ 0 且结果为负|❌ 不进位|负数向上舍入仍变小|
|**RDN（向 −∞）**|舍弃部分 ≠ 0 且结果为负|✅ 进位|若负数且丢弃部分非零 → 加 1（数值更负）|
||舍弃部分 ≠ 0 且结果为正|❌ 不进位|正数向下舍入仍变小|

- **units in the last place(ulp) ：**相邻两个浮点数之间在数值上的差距（其实就是分度值），作为用来衡量误差的单位
