# 二项队列

**二项队列(Binomial Queue)** 也是优先队列的一种实现，只不过不同于之前我们用一个堆维护优先队列，二项队列同时维护了具有不同特征的若干队列。

1. 可变堆结构，merge很快，但插入操作复杂度
   - worst case：$O(logN)$

2. 经典堆，插入操作复杂度
   - 按概率随机分布：$O(1)$
   - 即，经典堆中1/2的结点为叶子，1/4为叶子的父节点，依此向上类推...最后可算得插入其实是均摊常数级的操作

所以我们希望做到综合以上优点：merge为$O(logN)$，insert为$O(1)$ → Binomial Queue

### 1.2 二项队列

二项树对点的数量具有比较严格的要求，只有点的数量符合 2^k(k=0,1,2...)时，才能使用二项树表示。因此，观察一个二项树能承载的点的数量特征，我们联想到二进制对于数的表示——我们可以用一系列二项树来维护 N 个节点的优先队列，而具体用哪几阶二项树，则取决于 N 的二进制表达中，为 `1` 的是哪几位。

**二项队列(Binomial Queue)** 是一系列**二项树(Binomial Tree)** 的集合，其中每个二项树的阶数 k 都是不同的，反过来讲这句话，集合中 k 阶的二项树要么只有一个，要么没有。

可以用数组Q来表示二项队列，Q[k]中存放$B_k$的指针。

## 2.操作

### 2.1 FindMin

N个结点的二项队列，最多有logN棵树，那么遍历找出所有root里最小的即可，T = O(logN)
>proof: $2^m \le N \le 2^{m+1}$，则N的二进制表示最多有$m=\log_2N$位，每位一个树。 

或者为Min加上个记号，在构建队列时进行一些额外的维护操作，从而FindMin为O(1)



### 2.2 Merge

同阶归并，恰好能与二进制数的按位加法相对应。

![5-6](../image/2025-11-10-16-26-45.png)

- 在合并两个二项树时，可以直接将根节点较大的二项树置为另一个二项树的**左儿子**。好处1是合并时只用修改2个指针；好处2是这样就能以极小的代价保证 Bk​ 根节点的所有儿子以 Bk−1​,⋯,B1​,B0​ 的顺序排序，有利于后续删除操作。（与上图中放置相反）

- 复杂度与二进制表达的位数，也就是二项树的个数有关，故为O(logN)。但是要求二项队列中的树要有序排列，从而才能直接【按位相加】

- 若进位后有3个同阶的Bk，此时为了方便可以直接合并原有的Bk；不过也可以合并其中root值最大的那个和另一个树，这样那个最大的值就不是root了，从而可以加快FindMin操作。

### 3.3 Merge

```c
BinQueue Merge(BinQueue H1,BinQueue H2)
{
    BinTree T1,T2,Carry = NULL;
    int i,j;
    if(H1->CurrSize + H2->CurrSize > Capacity)
        Error();
    H1->CurrSize += H2->CurrSize;
    //i代表阶数，j是当前队列的大小。注意队列的大小总是2的幂
    for(i=0,j=1;j<=H1->CurrSize;i++,j*=2)
    {
        T1 = H1->TheTrees[i];
        T2 = H2->TheTrees[i];
    
        switch(4*!!Carry + 2*!!T2 + !!T1)
        {
            case 0:
                case 1: break;
            case 2: //010
                H1->TheTrees[i] = T2; 
                H2->TheTrees[i] = NULL;  break;
            case 4: //100
                H1->TheTrees[i] = Carry;
                Carry = NULL;   break;
            case 3: //011
                Carry = CombineTree(T1,T2);
                H1->TheTrees[i] = H2->TheTrees[i] = NULL;   break; 
            ......
        }   
    }
    return H1;
}
```

- switch那句: 若T1是NULL,!T1 = 1. !!T1 = 0.也就是说，双!就是**将指针状态变为0或1的值**

- j*=2：从低位向高位遍历Queue，j>总结点数则停下。（因为 i 变量是找不到循环终点的，所以要引入一个 j 来track节点数量）
